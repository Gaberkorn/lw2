# lw2
Лабораторная работа №2. Алгоритмы и абстрактные структуры данных
Задание №1. Стек. Вариант 2. 
Задано логическое выражение. Необходимо вычислить его значение. В выражении могут встречаться знаки: ! (отрицание), & (конъюнкция, логическое «и»), | (дизъюнкция, логическое «или»), ^ (XOR — «исключающее ИЛИ», «ровно одно из двух — истина») и скобки. Самый высокий приоритет у отрицания, меньше — у &, а операции | и ^ имеют самый низкий приоритет
(одинаковый) и вычисляются слева направо. Все числа в выражении либо 0, либо 1.

Задание №2. АТД Множество
Реализовать основные операции со множеством: добавление элемента, удаление элемента, проверка наличия элемента в множестве.
Запуск задания в консоли:
./<имя вашей программы> --file <путь до файла с данными> – query <запрос к файлу с данными>
Все операции выполняются за O(1).

Задание №3. Множество. Вариант 2. 
Значение логического выражения. Схожие подмножества. Необходимо реализовать алгоритм, который должен разбить множество натуральных чисел на непересекающиеся подмножества, разница между суммами которых была бы минимальна. Вывести получившиеся подмножества и разницу их сумм. Пример: Дано множество S = {5, 8, 1, 14, 7}.
Тогда получим два подмножества: {5, 14} и {8, 1, 7}.
Разница между их суммами равна 3.

Задание №4. Массив Вариант 2. 
Поиск суммы. Необходимо реализовать алгоритм, который находит подмассив, сумма элементов которого равна заданному числу. Пример:
Массив [4, -7, 1, 5, -4, 0, -3, 2, 4, 1], цель 5.
Подмассивы: [5], [4, 1], [5, -4, 0, -3, 2, 4, 1], [1, 5, -4, 0, -3, 2, 4]

Задание №5. Двоичное дерево. Вариант 2. 
Чтение змейкой.Реализовать алгоритм, который будет выводить содержимое дерева "змейкой". Использовать очередь для достижения O(n).

Задание №7. LFU кэш 
Разработайте структуру данных, которая работает как кэш LeastFrequentlyUsed. На вход подается запрос, который может быть двух типов:
• SET x y: устанавливает значение ключа x со значением y. Если ключ x уже есть, то значение перезаписывается на y. Если кэш достигает своей емкости, должен быть аннулирован элемент, к которому обращались реже всего.
• GET x: возвращает ключ x, если он присутствует, иначе возвращает -1. В конструкторе класса должна быть инициализирована емкость кэша.
